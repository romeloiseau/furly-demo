# Furly · démo

Version web de démonstration de Furly, l'application qui regroupe les services pour animaux du Grand Montréal.

**Essayer la démo : https://romeloiseau.github.io/furly-demo/**

- Toutes les données sont fictives (prestataires, rendez-vous, messages). Aucun vrai compte n'est créé, aucun
  courriel n'est envoyé, aucun paiement n'est fait.
- Compte de démonstration : `marie.dupont@exemple.ca` / `Furly2026!`. On peut aussi créer un compte propriétaire,
  pet sitter ou entreprise : il reste dans ce navigateur.
- Ce dépôt ne contient que le site déjà construit ; le code source est dans un dépôt privé.
