# kinipaw · démo

Version web de démonstration de kinipaw, l'application qui regroupe les services pour animaux du Grand Montréal.

**Essayer la démo : https://romeloiseau.github.io/kinipaw-demo/**

- Les prestataires, rendez-vous et messages de démonstration sont fictifs ; aucun paiement n'est fait.
- Compte de démonstration (fictif) : `marie.dupont@exemple.ca` / `kinipaw2026!`.
- Les comptes créés ici (propriétaire, pet sitter, entreprise) sont de **vrais comptes**, enregistrés de façon
  sécurisée dans la base de données de kinipaw (Supabase, au Canada).
- Ce dépôt ne contient que le site déjà construit ; le code source est dans un dépôt privé.
- Design : « Redesign D » — fond crème, six couleurs vives, Bricolage Grotesque et DM Sans, surfaces posées
  par une ombre douce. La planche complète du système est à l'adresse `/design-system`.
